# KairosAI Round 2 Demo

This is a standalone, offline-friendly controlled attack simulation prototype.

Open `index.html` in Chrome.

Demo:
1. Click Port Scan / SYN Flood / ARP Spoofing.
2. Show the generated telemetry.
3. Show the detection alert.
4. Show the plain-English explanation.
5. Show incident history.
6. Reset and repeat.

Important:
- This prototype does not send disruptive traffic.
- The detection events are controlled simulations.
- The explanation layer is a deterministic fallback for offline demonstration; it is not a live Llama/Ollama call.
- Do not present simulated values as measured benchmark results.
